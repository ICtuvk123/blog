Structural position encoding

Structural-aware attention mechanisms

GT leverages the graph structure to first generate a structure matrix that encodes node connectivity patterns. This structure matrix can be integrated into the attention matrix by three ways:

  1. attention bias
  2. by attention mask
  3. by edge-level tokenization.
