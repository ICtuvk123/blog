Modality Importance Calculation

  • First, we compute the maximum value across the last dimension for each element, resulting in maxk(Am,n,k) ∈ RM×N .
  • Next, we compute the average across the sequence dimension (the last dimension) of maxk(Am,n,k) to obtain the statistical information as the modality importance indicator
  • We define the number of uninformative tokens for the m-th modality as Km = floor(s[m] × N ). Thus, we prune Km tokens in the m-th modality and impute them using intermodal tokens {xm′ }M m′̸=m.

Customized token fusion

  • The first-level contrastive learning objective LI uses features from the same instance as positive inputs and features from other instances as negative inputs
  • The second-level contrastive learning objective LT uses the n-th token from different modalities of the same instance as positive inputs, while tokens from other instances serve as negative inputs
