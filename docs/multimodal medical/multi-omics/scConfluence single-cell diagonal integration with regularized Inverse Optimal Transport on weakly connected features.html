Background

problem

  • Indeed, connections between the features of different modalities are generally known in biology
  • Most of the state-of-the-art methods use this prior biological knowledge to convert all modalities to the same features and then handle the alignment similarly to batch effect correction
  • Indeed, acrossmodality feature connections are often rare and noisy
  • However, they still depend on the assumption that most features can be reliably connected across modalities
  • a population of cells (cell type/state) can be present only in one modality, which is frequently the case for unpaired data

solution

  • we propose scConfluence, a diagonal integration method combining uncoupled autoencoders, which reduce the dimensionality of the original data to a shared latent space and account for potential batch effects, together with regularized Inverse Optimal Transport (rIOT)32, which aligns cells across modalities in the shared latent space by leveraging weakly connected features
  • thanks to the unbalanced relaxation of Optimal Transport33, scConfluence can also deal with cell types absent in a modality thus overcoming all the major limitations of the state-ofthe-art
