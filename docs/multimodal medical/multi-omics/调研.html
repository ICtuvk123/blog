生成式共享潜空间 + GAN

multimodal medical · 更新于 2026-03-30

现在单细胞多组学这个方向，本质上是在做一件事——把不同来源、不同测量方式的细胞数据（比如RNA、ATAC、蛋白）放到同一个可比较的空间里，同时还能互相推断缺失的信息。但这个问题难就难在几个地方：首先大多数数据是非配对的，也就是说不同模态往往不是来自同一个细胞，几乎没有直接监督信号；其次不同模态的特征空间完全不一致，比如RNA是基因表达，ATAC是染色质开放区域，它们之间没有天然的一一对应关系；再加上单细胞数据本身噪声大、掉零严重，使得模型很容易学到技术噪声而不是真正的生物信号。

围绕这些问题，目前的方法大致分成几类：一类是做共享潜空间，用VAE或者对抗训练把不同模态映射到同一个latent space里，这类方法实现简单、效果也不错，但很容易出现“分布对齐了但细胞错配”或者过度混合的问题；另一类是基于最优传输或流形对齐，更强调保持细胞之间的几何结构，不过计算代价高，而且对距离定义非常敏感；还有一类方法引入生物先验，比如基因调控网络或pathway信息，希望用这些知识约束对齐过程，但问题在于这些先验本身并不完全可靠，反而可能带来偏差。

整体来看，这个领域现在最大的瓶颈并不是模型结构本身，而是几个更根本的问题：一是如何在“对齐不同模态”和“保留真实生物结构”之间找到平衡；二是如何把不同模态中共享的信息和模态特有的信息真正分开；三是如何学习到可信的跨模态对应关系，而不是依赖粗糙的人工构造；以及最后一个常被忽略但很关键的问题——我们其实缺乏可靠的评估标准来判断对齐到底是不是“对的”。所以如果要做研究的话，重点往往不在再造一个更复杂的模型，而是在这些更本质的问题上找到突破，比如更好的解耦表示、更稳健的对齐方式，或者把生物先验和数据驱动的方法结合得更合理。

生成式共享潜空间 + GAN

scGLUE 动机： 解决“非配对多组学 + 异质 feature 空间 + 缺乏生物学约束”的整合问题

贡献：把调控图嵌入到生成模型中，让不同组学在同一调控语义空间中对齐，同时实现大规模整合和调控推断

方法： !Pasted image 20260303090845.png GLUE 为每个组学分别构建 VAE 学习共享维度的细胞嵌入，并利用包含跨组学调控关系的指导图，通过图 VAE 学习特征嵌入，使细胞嵌入与特征嵌入通过内积重构数据，从而在几何上连接不同组学空间。最后通过对抗判别器对齐不同组学的细胞嵌入分布，实现跨模态整合。

局限： 强依赖先验图质量 decoder 是线性的

scMODAL 动机： 在很多单细胞多组学场景中，不同模态之间特征关联弱（如 RNA–protein）、细胞不配对且特征数差异大，单纯做分布对齐容易错配细胞或过度整合，同时又缺乏跨模态补全能力

贡献： scMODAL 构建共享潜空间的生成式框架，通过非线性编码器 + 对抗训练实现分布对齐，并利用少量 linked features 构建 MNN 锚点约束和几何保持正则，保证对齐准确且结构稳定，同时支持跨模态重构与特征补全。

方法： !Pasted image 20260303145658.png

scMODAL 用两个非线性编码器把不同组学映射到同一个共享潜空间，通过重构约束$E2​(G2​(E1​(x1​)))≈E1​(x1​)$和对抗训练（GAN）实现跨模态分布对齐。为避免错配和过度整合，它结合少量先验链接特征构建锚点约束，并加入几何结构保持正则，使对齐既混合充分又保留生物结构。

可借鉴点： 重构约束$E2​(G2​(E1​(x1​)))≈E1​(x1​)$ 用MNN pairs防止对抗对齐造成的语义错配问题

scCross

动机 现有多组学整合方法难以在完全或部分 unpaired 情况下同时实现稳定整合、跨模态生成 不同模态数据质量和特征空间差异大，容易导致分布混合但细胞错配

贡献 scCross 构建 VAE + 共享潜空间 + 对抗对齐的生成式框架，通过 MNN 锚点约束保证细胞级匹配，并在统一潜空间中实现跨模态生成、多模态模拟。为整合后的功能推断提供一体化解决方案。

方法 !Pasted image 20260303151249.png 先用KNN和GCN的方法对每个模态得到自己的embedding，然后拼接上由先验知识能够确定的映射到gene模态的embedding，然后每个模态分别训练 VAE 学习模态特异表示，随后通过一个双向对齐器将各模态 latent 映射到共享潜空间，在该空间中利用 GAN 做分布对齐，同时结合基于共同基因的 MNN 锚点约束保证细胞级正确匹配

可借鉴点： 这种对不同模态的embedding方式会比直接第一步就做一个粗糙的不同模态到gene层面的mapping保留更多的生物信息，但是protein模态的特征数比较少，不一定能够得到效果好的embedding

局限

  1. 需要“共同基因”来做 MNN prior：作者的细胞级锚定依赖把各模态转成 gene-centric 表示（如 ATAC/甲基化→gene activity），因此当模态与基因空间关系弱或难以可靠转换时，锚点质量会下降
  2. 模型设计较复杂，VAE里面套VAE，训练成本高

Monae 动机： 多模态单细胞数据常见“细胞不配对+特征不一致+噪声/掉零”，而配对测序昂贵稀缺，所以需要能在完全无配对条件下同时把模态拉到同一空间并补全缺失信号的深度学习框架

贡献： 把“跨模态调控关系图学习 + 细胞对比学习”合在一起做整合+同模态去噪+跨模态翻译，并提出 Monae-E 通过把细胞/可选 motif 也作为图节点引入更多生物知识来加速收敛、提升可解释发现能力

方法 !Pasted image 20260304154935.png 用跨模态调控“指导图”先学出各模态特征的图嵌入F，再用对比学习在每个模态内训练细胞嵌入U，最后用统一的矩阵分解解码 $X_k = U_k * F_K^T$ 同时实现同模态去噪、跨模态翻译与联合整合

借鉴点： 用对比学习把细胞空间做得更稳、更可分

局限：

  1. 高度依赖指导图/边符号的质量与预处理
  2. $U_k * F_k^T$是低秩的，表达力有限

Portal 动机：百万级可扩展性、复杂组织中稀有/细粒度亚群保留、以及跨平台/跨物种的异质域效应

贡献：把不同数据集视为“不同域”，用统一的对抗式域翻译在分钟级、低内存下完成大规模对齐并尽量避免把域特异细胞型“过校正”掉

方法编码器去除域效应、生成器模拟域效应、判别器在域内对抗训练并显式区分域共享/域独有类型，再加三类正则（自编码一致性、跨域对应、潜空间对齐）保证可解释对齐

!Pasted image 20260304204758.png

局限 对抗训练本身可能带来训练不稳定/超参敏感，且“域独有”判别若失准仍可能漏对齐或保留残余批次效应

OT / GW / UOT

Pamona

动机： 现有多组学流形对齐方法默认不同数据集完全共享同一潜在结构，但现实中往往同时存在共享与特异细胞群体，因此需要一种能只对齐共享部分而保留特异结构的整合方法

贡献： 贡献在于提出将多组学整合表述为 partial Gromov–Wasserstein 最优传输问题，通过虚拟节点实现部分匹配，从而同时完成共享细胞对齐与特异细胞识别

方法 !Pasted image 20260303162518.png 先在各模态内部构建 kNN 图并计算测地距离，再用 partial-GW 求得跨模态概率耦合矩阵，让 X 内部的距离结构与 Y内部的距离结构在匹配后尽量一致，最后在保持局部几何结构的约束下用Laplacian eigenmap学习共同低维嵌入

借鉴点： “部分匹配”这一建模视角，以及用结构距离而非特征对应来完成跨模态对齐，同时通过虚拟节点处理数据集特异结构

局限 需要估计共享细胞数量这一关键超参数，计算与内存开销较大，并且对 kNN 图和距离估计质量较为敏感

scCotag 动机： 现有对角整合方法要么忽略不可靠的生物先验，要么假设所有细胞都可对齐，在存在模态特异细胞或比例不平衡时容易过度对齐并扭曲几何结构；同时，先验（如 gene–peak 关系）往往带噪却被当作固定真值使用。

贡献 scCotag 提出动态先验驱动的 Co-optimal Transport，同步学习细胞级与特征级传输计划，并通过对齐置信度识别锚点细胞、结合几何正则避免错误强配对，在不平衡和弱先验条件下实现更稳健的多组学对角整合。

方法： !Pasted image 20260303135430.png

用带动态先验的双层 OT 先学跨模态对应关系，再用这些 transport plan 反过来约束深度生成模型的表示学习，实现稳健且结构保持的多组学对角整合

可借鉴的地方： 通过对齐置信度识别锚点细胞

局限： 计算成本高 只验证了 RNA + ATAC 只针对“modality-unique cells”这种 imbalance

Uniport

动机： 现有单细胞整合方法要么依赖线性假设、只用共同基因，要么要求配对细胞或全局对齐，难以统一处理异质多组学与空间转录组数据，因此作者提出一个同时适用于多模态与空间数据的统一框架

贡献： 将 coupled-VAE 与 Minibatch-Unbalanced OT 结合，在同一框架下实现多组学嵌入、基因插补与空间去卷积，并同时利用共同基因与数据集特异基因进行整合

方法 !Pasted image 20260303182349.png 先用共享编码器将不同数据投射到公共潜空间，再通过 Minibatch-UOT 在潜空间对齐细胞分布，同时用数据集特异解码器重构特异基因，最终最小化 ELBO 与 UOT 损失的加权和

局限

  1. 包含多超参数与网络结构设计
  2. OT计划存储与训练过程在大规模数据下仍存在内存与计算开销问题

scConfluence 动机： 在真实场景中，跨模态数据往往只有少量或群体层面的弱配对信息，既不足以做监督对齐，又比完全无先验更复杂；直接设定固定距离做 OT 容易错配或过度传播错误匹配。

贡献： scConfluence 引入正则化的逆最优传输（Inverse Optimal Transport），利用弱配对信息反向学习合理的跨模态代价函数，再在该代价下求解 OT，实现更稳健的细胞级对齐，并通过结构正则避免几何扭曲

!Pasted image 20260303160857.png 在弱配对信息（如少量已知对应关系）的指导下，通过 逆向最优传输 学习跨模态的代价函数，使这些弱监督匹配在最优传输框架下成为合理解；随后在学得的 cost 上求解正则化 OT，实现细胞级对齐，并通过结构正则避免几何扭曲。

局限

  1. 依赖弱配对信息质量
  2. 计算成本较高

连续结构与结构距离保持

scDART 动机：

  1. scRNA–scATAC 的整合方法先用一个预定义的 gene activity matrix（GAM）把 ATAC 线性“翻译”成 RNA，但这种 GAM 往往质量低、且不反映数据集特异的调控关系
  2. 同时在连续细胞群（轨迹/分化树）里，保留“轨迹身份”比保留离散簇更难

贡献： 提出 scDART，把“跨模态翻译（ATAC→RNA）”和“跨批次/跨模态对齐”做成一个端到端联合优化：用神经网络学习非线性的 gene activity function，而不是固定线性 GAM，并在共同潜空间里让两模态“合并到同一条轨迹”

方法 !Pasted image 20260303202026.png 用神经网络将 ATAC 转为 pseudo-RNA，再通过共享投影网络映射到共同 latent 空间，并以 MMD 对齐分布、以 diffusion 距离保持各自轨迹结构，同时用 GAM 作为结构先验正则

借鉴点

  1. 把跨模态翻译建模为可训练函数并加入生物先验约束
  2. 用diffusion distance保护细胞轨迹结构

局限： 依赖 GAM 质量与多重超参数设置

知识图谱嵌入

SIMBA 动机： 现有多模态单细胞整合方法往往假设模态间完全共享结构或依赖强特征对应，在存在模态特异结构或复杂调控关系时容易产生错误对齐，因此需要一种更稳健、可扩展且对结构差异更容忍的整合框架

贡献： 提出一种基于深度模型与分布对齐/结构保持相结合的多模态整合方法，在无需严格配对细胞的情况下实现跨模态对齐，并在大规模数据上验证其稳定性与泛化能力

方法 !Pasted image 20260304080046.png

把细胞、基因、ATAC peak、motif、k-mer 等都当成图节点，把“观测到的关系”（如 cell–gene 表达、cell–peak 可及、peak–motif/peak–kmer 序列包含、以及可选的 peak–gene 调控关联）当成边，先用大规模图嵌入学习所有节点的向量，再用 softmax-based transformation 把不同类型实体的表示拉到同一可比较空间里，最后所有跨模态整合/marker 发现/调控解释都变成在这个共同空间里做近邻检索

局限性：

  1. 跨模态连接强度依赖桥梁边的质量
  2. 离散化/二值化会丢信息

弱链接+ 迭代锚点强化

SuperMap 动机： 大量单细胞多模态数据是“无配对”的、特征空间也不同，缺少跨模态锚点会让对齐、调控分析等下游任务很难做；现有方法要么靠粗糙的生物先验（如基因活性分数/距离图），要么需要额外的配对数据，都会带来偏差或不现实

贡献： 直接在无配对条件下从数据里学“跨模态特征映射”，把学到的映射当作 linkages 去做缺失模态插补、提供更高质量 anchors 做 diagonal integration、并进一步支持 peak–gene 调控推断与轨迹方向/epigenomic priming 分析

方法 !Pasted image 20260304145636.png 核心建模是把“同一生物系统的两批细胞”视为分布同构，并用回归刻画跨模态因果方向：$y\=Bx+ϵ$，合起来就是$y \overset{d}{=} Bx+\epsilon$（用边际分布+二阶交互来拟合 joint，配合 ADMM 优化）同时把peak 越远调控越弱的先验写进正则：$\frac{\lambda}{2}\|D\circ B\|_F^2$​，其中 $D_{ij}=\exp(d_{ij}/d_0)$，并对>200kb或跨染色体的$B_{ij}$直接置零以缩小参数空间；为抗噪声，拟合阶段用 meta-cell，插补/对齐阶段用 KNN smoothing 后再做 $Y^\=X\hat B^T$

借鉴点： 它把“找锚点/做对齐”的瓶颈上移到“先学出跨模态映射 B”，等于用数据自适应地替代了粗糙 gene activity score，再把这个更准的映射输出成通用组件（插补、anchors、调控强度、轨迹方向）去喂给现有分析管线

局限： 一旦细胞类型缺失/比例严重失衡或深度很低，映射会退化

MaxFuse 动机： 许多单细胞多模态整合场景中，不仅细胞不配对，而且不同模态之间的特征关联非常弱 需要一种在 弱 linkage 条件下仍能实现可靠跨模态匹配与整合的方法

贡献： 通过 迭代的联合嵌入、图平滑与细胞匹配 框架逐步强化跨模态对应关系，并设计 pivot 机制和匹配传播策略提升匹配稳定性，同时提供利用 RNA 作为中介的策略实现三模态整合

方法： !Pasted image 20260304162607.png

先做KNN，然后用linked feature做细胞匹配，再对不同的模态相匹配的细胞做CCA，循环此过程

局限性：方法仍依赖一定的特征对应关系作为起点，且假设两个数据具有相似细胞结构；同时联合嵌入基于线性 CCA，表达能力有限，对复杂非线性跨模态关系可能不足。
