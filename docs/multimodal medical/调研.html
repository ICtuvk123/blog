1. SURVPATH — CVPR 2024

multimodal medical · 更新于 2026-05-21

核心任务：多模态癌症生存预测 / 预后分析，主要把 病理全切片图像 WSI、基因组/转录组数据、病理报告、临床信息 等融合起来，预测患者风险、生存时间或生存分层

意义: WSI 看的是形态表型，组学看的是分子机制，病理报告看的是专家总结后的诊断语义。形态表型 + 分子机制 + 临床诊断语义 → 更完整的预后判断

1. SURVPATH — CVPR 2024

核心问题

WSI 和 bulk transcriptomics 的数据性质差异很大。WSI 是高维空间形态信息，描述肿瘤组织结构、细胞排列和局部形态模式；而 bulk transcriptomics 是全局基因表达信息，描述整个样本的分子状态。

因此，该任务面临两个主要问题：

  1. 如何将 transcriptomics 数据转化为具有生物学意义、可解释的 token；
  2. 如何建模 histology patch token 与 pathway token 之间的细粒度跨模态交互。

方法思路

SURVPATH 将 transcriptomics 表示为 biological pathway tokens，每个 token 对应一个具体的细胞功能或生物通路；同时将 WSI 切分为 histology patch tokens。

之后，模型使用 memory-efficient multimodal Transformer 建模 pathway tokens 与 histology patch tokens 之间的交互关系，用于生存预测。

2. PIBD — ICLR 2024

核心问题

多模态数据中存在大量冗余信息，影响模型提取紧凑且具有判别性的预后特征。

主要包括两类冗余：

  1. Intra-modal redundancy：单个模态内部存在大量与任务无关的信息。例如 WSI 中大量 patch 可能与生存预测无关，组学数据中也有大量 pathway 或 gene group 与预后关系较弱；
  2. Inter-modal redundancy：不同模态之间存在重复信息，容易导致模型过度关注 common information，而忽视 modality-specific information。

方法思路

PIBD 提出 Prototypical Information Bottlenecking and Disentangling 框架，包括两个核心模块：

  1. PIB：Prototypical Information Bottleneck

    2. 用于减少单模态内部冗余，选择更有判别力的实例或特征。

  2. PID：Prototypical Information Disentanglement

    3. 用于分解多模态信息，将融合表示拆分为 modality-common knowledge 和 modality-specific knowledge，从而减少跨模态冗余并保留各模态独有信息。

3. MMP — ICML 2024

核心问题

现有方法通常将 WSI 切成大量 patch tokens，同时将 transcriptomics 表示为 gene groups，然后使用 Transformer 进行融合。

但这种方式会产生大量 tokens，导致两个问题：

  1. Transformer attention 计算开销和显存需求很高；
  2. 大量 tokens 之间的交互难以解释，影响模型的 post-hoc interpretability。

方法思路

MMP 提出 Multimodal Prototyping 框架。

它使用两类 prototypes 来压缩不同模态：

  1. Morphological prototypes

    2. 用于压缩 WSI 中大量 patch tokens，将整张切片中的形态信息总结为少量代表性形态原型，实现超过 300× 的压缩。

  2. Biological pathway prototypes

    3. 用于表示 transcriptomics 中的细胞功能和通路信息。

压缩后的 multimodal tokens 再输入 Transformer 或 optimal transport cross-alignment 模块进行融合，用于生存预测。

4. HEALNet — NeurIPS 2024

核心问题

很多多模态深度学习方法使用模态专属架构，并且往往分别训练各个模态模型。这种方式难以捕捉真正重要的 cross-modal information。

医学数据的异构性很强，包括图像、表格、组学、图结构等模态。这些模态不像图文任务那样有明确共享语义空间，因此跨模态关系更加复杂。

方法思路

HEALNet 提出 Hybrid Early-fusion Attention Learning Network。

该方法使用 shared latent embedding 来学习跨模态共享信息，同时保留 modality-specific parameter space 来保存每个模态的结构特征。

HEALNet 的目标包括：

  1. 保留每个模态自身的结构信息；
  2. 在共享潜在空间中捕捉跨模态交互；
  3. 处理训练和推理阶段的 missing modalities；
  4. 直接基于 raw data input 学习，提高模型可检查性。

5. LD-CVAE — CVPR 2025

核心问题

现有多模态生存预测方法通常假设测试阶段所有模态都完整可用。但在真实临床场景中，genomic data 获取成本较高，因此测试样本中可能缺失 genomics 模态。

因此，该任务面临两个主要问题：

  1. WSI 是 gigapixel 图像，表示学习难度很高；
  2. Genomic embeddings 具有不同功能类别，难以用统一生成框架进行建模。

方法思路

LD-CVAE 提出 Conditional Latent Differentiation Variational AutoEncoder，用于在 genomics 缺失时进行鲁棒的多模态生存预测。

方法包括三个关键部分：

  1. VIB-Trans

    2. 使用 Variational Information Bottleneck Transformer 从 gigapixel WSI 中学习压缩的 pathology representation。

  2. LD-VAE

    3. 学习 genomic embeddings 的 function-specific posterior，用于生成不同功能类别的 genomic features。

  3. Product-of-Experts

    4. 将 image posterior 和 genomic posterior 结合，估计 joint latent distribution。

6. DisPro — CVPR 2025

核心问题

现有 incomplete multimodal learning 方法在处理缺失模态时，通常只能补偿 missing modality 的部分信息。

主要问题是：

  1. 生成式 imputation 方法通常只能恢复 modality-common information；
  2. retrieval-based imputation 方法只能从训练集中寻找相似样本，补偿能力有限；
  3. imputation-free 方法主要学习 modality-invariant representation，容易忽视 missing modality 的 modality-specific knowledge。

方法思路

DisPro 提出 Distilled Prompt Learning 框架，利用 LLM 对缺失模态的鲁棒性进行信息补偿。

方法分为两个阶段：

  1. UniPro：Unimodal Prompting

    2. 学习每个模态自身的 knowledge distribution，用于补偿 missing modality 的 modality-specific knowledge。

  2. MultiPro：Multimodal Prompting

    3. 利用可见模态作为 prompts，让 LLM 推断缺失模态相关信息，用于补偿 modality-common knowledge。

最终，DisPro 同时补偿缺失模态的 common information 和 specific information。

7. PS3 — ICCV 2025

核心问题

PS3 处理的是 WSI、transcriptomics 和 pathology reports 三模态生存预测。

这三类模态存在明显异构性：

  1. WSI 是高维图像，包含大量 patch；
  2. Pathology reports 是长度不一的文本摘要；
  3. Transcriptomics 是基因表达数据，通常缺乏直接上下文结构。

这种差异会导致 modality imbalance，即某些信息量更大的模态可能在融合中占主导，而其他模态贡献被削弱。

方法思路

PS3 提出 prototype-based 三模态融合框架，将不同模态转化为更平衡的表示：

  1. Histological prototypes

    2. 用于表示 WSI 中的关键形态模式。

  2. Diagnostic prototypes

    3. 用于从 pathology reports 中提取诊断相关文本信息。

  3. Biological pathway prototypes

    4. 用于表示 transcriptomics 中的细胞功能和分子通路信息。

之后，模型使用 Transformer-based fusion module 建模三类 prototypes 之间的 intra-modal 和 cross-modal interactions，用于生存预测。

8. ModalTune — ICCV 2025

核心问题

现有 slide-level foundation models 通常只针对单一任务、单一癌种、单一模态进行微调，没有充分利用不同任务、模态和癌种之间的共享信息。

主要问题包括：

  1. 现有方法多为 single-task learning，难以利用 survival prediction、subtype classification 等任务之间的关系；
  2. 不同癌种之间的共享信息没有被充分利用。

方法思路

ModalTune 提出一个统一的多模态、多任务、pan-cancer fine-tuning 框架。

方法包括两个核心组件：

  1. Modal Adapter

    2. 在不修改 slide-level foundation model 主体权重的情况下，将额外模态信息接入 slide encoder。

  2. Text-based Multi-task Learning

    3. 使用 LLM 将不同任务标签编码为 text embeddings，使 subtype classification、survival prediction 等任务可以在统一语义空间中训练。

该方法希望在一个统一框架中同时利用多模态信息、多任务关系和跨癌种共享信息。

9. AMC — ICML 2025

核心问题

医学多模态数据中，不同模态对预测任务的贡献并不相同，而且这种贡献会随患者、癌种和数据质量变化。

主要问题包括：

  1. 不同模态的数据质量可能不同；
  2. 同一模态在不同癌种中的预测能力可能不同；
  3. 医学数据采集过程中的 batch effect、染色差异、测序质量差异等会影响模态可靠性；
  4. 固定融合策略难以适应这种动态变化。

方法思路

AMC 提出 Adaptive Modality Token Re-Balancing，是一种 top-down dynamic multimodal fusion 方法。

核心流程包括：

  1. 先评估每个模态的重要性或质量；
  2. 根据模态重要性决定保留多少 informative tokens；
  3. 对贡献较低的模态，用 inter-modal tokens 替换 uninformative tokens；
  4. 再通过 self-attention 融合重新平衡后的 tokens。

该方法的核心目标是让重要模态保留更多信息，让低质量或低贡献模态减少对融合结果的干扰。

10. SlotSPE — ICLR 2026

核心问题

现有方法在处理高维 WSI 和组学数据时，难以高效建模模态内部和模态之间的复杂交互。

更核心的问题是：患者预后往往由少数关键 prognostic events 决定，但这些事件通常具有以下特点：

  1. 数量少；
  2. 患者特异性强；
  3. 没有显式标注；
  4. 可能表现为空间组织模式、pathway co-activation 或形态-分子关联。

方法思路

SlotSPE 提出 slot-based structural prognostic event modeling 框架。

方法包括：

  1. 使用 slot attention 将每个患者的多模态输入压缩成一组 modality-specific slots；
  2. 每个 slot 表示一个潜在的 prognostic event；
  3. 使用 selective slot activation 激活对当前患者最有预测价值的 slots；
  4. 通过 cross-modal reconstruction 引入生物学先验，增强 WSI 与 genomics 之间的关联建模；
  5. 建模这些 slots 之间的 intra-modal 和 inter-modal interactions，用于最终生存预测。
