(QKT)V = Q(KTV)

CS336 · 更新于 2026-07-05

Recurrent form of linear attention Recall that in purely linear attention, we consider the reordering

(QKT)V = Q(KTV)

This is linear time (great) but the even nicer thing is that this looks like a RNN. St = St-l + ktvt and yt = qt St This 'duality' allows us to train efficiently (using the parallel, quadratic form) and inference efficiently (using the serial, linear form)
